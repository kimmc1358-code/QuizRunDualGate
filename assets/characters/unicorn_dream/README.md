# DREAM 모드 캐릭터 (유니콘)

이 폴더에 아래 3개 파일을 **정확한 이름으로** 넣으면 코드 수정 없이 바로 적용됩니다.
파일이 없는 동안에는 SKY 모드의 새 아트로 자동 대체되므로, 3개를 한꺼번에
넣지 않고 하나씩 넣어도 게임은 계속 정상 동작합니다.

| 파일명 | 용도 | 형식 |
|---|---|---|
| `unicorn_run.png` | 달리는 모습 (기본 상태) | **가로 5프레임 스프라이트시트 1장** |
| `unicorn_happy.png` | 게이트 통과 성공 | 단일 프레임 |
| `unicorn_sad.png` | 실패 / 게임오버 | 단일 프레임 |

## unicorn_run.png 배치

5프레임이 **가로로 일렬** 배치된 것으로 가정하고 설정해 두었습니다
(`MODE_CHARACTER_SHEET_GRID`의 DREAM 항목 = `Vector2i(5, 1)`).

```
+-------+-------+-------+-------+-------+
|   1   |   2   |   3   |   4   |   5   |
+-------+-------+-------+-------+-------+
```

- 각 칸의 크기는 **모두 동일**해야 합니다. 코드가 전체 너비를 5로 나눠 자릅니다.
- 재생 순서는 왼쪽 → 오른쪽, 8 FPS로 무한 반복합니다.
- 세로 5칸이거나 다른 배치라면 알려주세요 — 위 상수만 바꾸면 됩니다.

## 공통 사항

- 배경은 **투명(알파 채널) PNG**여야 합니다.
- 세 파일의 캔버스 크기와 캐릭터 위치를 서로 맞춰 주세요. 표정이 바뀔 때
  캐릭터가 튀어 보이지 않습니다. (`unicorn_run.png`은 한 칸 기준)
- 실제 렌더 크기는 100x100 근처로 축소되므로 원본은 그보다 크면 됩니다.
  다른 모드는 한 프레임이 256px 정도입니다.

## 넣은 뒤 조정할 수 있는 값 (scripts/Main.gd)

파일을 넣고 나서 위치·크기가 어긋나 보이면 아래 배열의 **네 번째 값**(DREAM)을
조정하면 됩니다.

- `MODE_DRAW_OFFSET_FLY` / `_HAPPY` / `_SAD` — 그리는 위치 미세 조정 (px)
- `MODE_VISUAL_SIZE_SCALE` — 이 모드만 살짝 크게/작게
- `MODE_CHARACTER_SHEET_GRID` — 시트 격자 (열, 행)

히트박스(`PLAYER_SIZE`)는 위 값들과 무관하게 고정이므로, 겉모습을 조정해도
게임플레이 판정은 변하지 않습니다.
