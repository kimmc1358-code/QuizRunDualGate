## 9-slice 로 쓸 예정입니다

셋 다 크기를 자유롭게 늘려도 모서리가 뭉개지지 않도록 9-slice(NinePatch)로
처리합니다. 그래서 그림을 이렇게 그려 주시면 가장 깔끔합니다.

```
   ┌────┬──────────┬────┐
   │ 모 │   가로    │ 모 │   ← 모서리: 절대 늘어나지 않음
   ├────┼──────────┼────┤
   │세로│   중앙    │세로│   ← 가운데: 가로·세로로 늘어남
   ├────┼──────────┼────┤
   │ 모 │   가로    │ 모 │
   └────┴──────────┴────┘
```

- **모서리 장식(둥근 테두리, 리벳, 보석 등)은 네 귀퉁이 안에** 들어가야 합니다.
  귀퉁이 영역을 넘어 변으로 뻗어 나가면 늘어날 때 잘리거나 반복됩니다.
- **변(가장자리)의 무늬는 일정한 패턴**이면 좋습니다. 늘어날 때 그 구간이
  잡아당겨지므로, 한가운데에 큰 장식이 있으면 왜곡이 보입니다.
- **중앙은 단색이나 완만한 그라데이션**이 안전합니다.
- 배경 투명(알파 채널) PNG로 주세요.

## 크기 참고

게임 화면은 **480 × 854** 입니다.

- 팝업 창: 화면 가로의 80% 안팎(약 **380px**)으로 표시될 예정입니다.
  원본은 그보다 크게(예: 폭 600~760px) 그려 주시면 축소되며 선명해집니다.
- 버튼: 팝업 안에서 **가로 260~300px, 세로 70~80px** 정도로 표시됩니다.
  원본은 2배 안팎이면 충분합니다.

버튼 두 개는 **같은 캔버스 크기·같은 모서리 반경**으로 맞춰 주세요.
나란히 놓았을 때 높이와 곡률이 어긋나지 않습니다.

## 넣으신 뒤

파일을 받으면 제가 각 이미지의 실제 모서리 크기를 측정해서 9-slice 여백
(`patch_margin`)을 잡고, 늘렸을 때 깨지지 않는지 확인해 드리겠습니다.
글자는 이미지에 넣지 말고 비워 두세요 — 팝업 종류마다 문구가 달라서
코드에서 얹습니다.

## 만들 팝업 (참고)

1. 일시정지

3. 게임오버 — 로그인 여부 × 신기록 여부 = 4가지

버튼 문구와 배치만 다르고 판·버튼 이미지는 공용입니다.
